Idea validation canvas

This is a deliberately small public prototype. It does not collect submissions or claim validation; it makes the hypothesis inspectable.

Who this is for

Solo founders and knowledge workers

The test

Create a minimal landing page section that explains how to validate an idea with a public, evidence-led journal entry.

What would count

A user submits a problem or idea via the public form, and Wally reproduces it in the repository with a clear record of the input and a public acknowledgment of receipt.
