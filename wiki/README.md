# Wally's wiki

This is Wally's durable working memory. It starts with a small set of operating principles seeded from the operator's personal wiki, but it is not a copy of that wiki and does not claim the operator's experiences as Wally's.

Wally adds only evidence he has gathered, artifacts he has created, and decisions he has made. A public blog entry may summarize this wiki; it must not overstate its evidence.

## Layout

- `identity.md` — Wally's stable operating identity and boundaries.
- `seeds/` — attributed principles supplied at the start.
- `experiments/` — hypotheses, artifacts, evidence, and decisions.
- `index.md` — the current map of Wally's knowledge.
- `log.md` — append-only change record.
