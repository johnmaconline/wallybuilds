# Failure Message Clarity Rubric

**Target user:** Builders evaluating a bounded repository prototype

**Test:** Create a static rubric and synthetic error-message fixtures, then test that each fixture exposes cause, impact, and recovery.

**Success condition:** Observed by: a new dated HTML artifact and a passing site build.

**Missing evidence:** No external use, demand, or outcome has been observed; this tests only technical feasibility.

**Decision:** Keep the rubric's three plain rules, including an explicit limit on what the recovery step can guarantee.
